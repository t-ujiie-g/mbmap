mbmap examples

  • basic — MoonBit のビルドを直接読む最小の例。?remote=1 で国土地理院の配信タイル（全国・z4〜16）を読む。
  • npm — npm パッケージを import { Map } from "mbmap" で使う例（スタイルは URL で渡す）。
  • geojson — スタイルに GeoJSON ソース（URL とインライン）を書く例。属性で塗り分けた面・線・点を、国土地理院のタイルの上に重ねる。
  • analysis — mbmap/analysis で点をブロックごとに数え、その結果で塗り分ける例（解析は専用の Worker で動く）。
  • terrain — 国土地理院の標高タイルから富士山の陰影起伏（hillshade）を立体の地形に貼って描く例。?remote=1 で配信中の標高タイルを読む。
  • element — 素の HTML に <mb-map> を置く例。
  • react — React 19 から <mb-map> を使う例（左上のボタンでズーム、ホイールで動かすと表示が追従する）。

npm / geojson / analysis / element / react は、npm pack した成果物を各フォルダの node_modules に入れて動かす。 npm --prefix bench run examples で準備と配信をまとめて行う。タイルは東京駅周辺の z14（bench/fixtures）。 出典：国土地理院ベクトルタイル提供実験
