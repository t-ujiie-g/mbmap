mbmap examples

同じ地図アプリを 3 通りの書き方で作っています。2D と 3D（地形・建物・空）の切り替え、地点への移動、カメラの状態と平面直角座標、中心から 5 km 以内の地点（mbmap/analysis のバッファと点の判定）を表示します。

  • 素の HTML — import { Map } from "mbmap" と DOM で書く。
  • Web Component — <mb-map> の属性・プロパティ・イベントで書く。
  • React — React 19 から <mb-map> を JSX で使う。

地図は国土地理院の配信タイルを直接読みます（出典：国土地理院ベクトルタイル提供実験、国土地理院 標高タイル）。?local=1 を付けると、ベンチ用に取得した東京駅周辺の z14 のタイル（bench/fixtures）を読みます。
