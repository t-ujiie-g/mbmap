mbmap

MoonBit で書いた、Web のためのベクトルタイル地図エンジン。同じ地図アプリを 3 通りの書き方で作っています。

書き方を選ぶ

HTML素の DOM から使うimport { Map } from "mbmap" Web Component属性とイベントで使う<mb-map center="139.77,35.68"> ReactReact 19 の JSX から使う<mb-map onmb-load={onLoad} />

アプリでできること

探す
地名と座標の検索、地点への移動、クリックした地物、周辺の地点
レイヤー
2D と 3D（地形・建物・空）、地図と空中写真、レイヤーの切り替え、凡例
作図
点・線・多角形・円、編集、スナップ、分割と結合
計測
楕円体の上の距離と面積、標高の断面図
解析
ボロノイ領域の階級区分図と凡例、道路での経路探索、見通しと可視域
データ
CSV、Shapefile、KML、GPX などの読み込みと書き出し、属性テーブルと列の計算
地図は国土地理院の配信タイルを直接読みます（出典：国土地理院ベクトルタイル提供実験、国土地理院 標高タイル）。?local=1 を付けると、ベンチ用に取得した東京駅周辺の z14 のタイル（bench/fixtures）を読みます。
